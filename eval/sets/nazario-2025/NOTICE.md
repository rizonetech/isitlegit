# Nazario phishing corpus: attribution

The 49 messages in this folder are from Jose Nazario's phishing corpus, mailbox `phishing-2025` (https://monkey.org/~jose/phishing/), licensed under the Creative Commons Attribution 4.0 International licence (CC BY 4.0, the full text in `LICENSE.txt` beside this file; https://creativecommons.org/licenses/by/4.0/). The corpus README reads: "The license for these files is CC-BY-4.0, enabling derivative works and commercial use but does require attribution."

Changes: 49 of the mailbox's 481 messages were selected (those whose evidence our checks read is plain in the message, leaving out any that name a client of ours) and each is stored as its own `.eml` file, byte for byte as the mailbox holds it, without the mbox `From ` separator line. Nothing in a message was added, removed or altered. The labels in `labels.json` are IsItLegit's own.
