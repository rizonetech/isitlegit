# Codex unattended continuation

The coordinator owns shared lifecycle tooling and D00 from 4 November 2026. All lanes run unattended with no blocking questions. User stops, session ownership, product safety and honest review evidence remain mandatory.

Native hooks own continuation and interruption. State lives outside Git in `~/isitlegit-data/handover/codex-continuation/`, one locked record per lane. Activation explicitly selects a session and canonical worktree. Foreign hook events never claim ownership. Interrupt pauses the owner until an explicit activation. Stop can continue an enabled owner whose final outbox wait is `none`; other waits leave an idle state for later inspection. No model output is treated as a machine instruction.

WORKAROUND: the installed Codex API exposes no native recurring scheduler. A user-systemd timer runs a bounded heartbeat every five minutes through the supported `codex queue --thread SESSION --message TEXT --resume` interface. It is a host heartbeat, never a native Codex job. A queue result is only queued, not delivered. The next matching lifecycle event acknowledges it. Active sessions, paused sessions and missing lifecycle evidence never receive a wake. An outstanding wake is not queued repeatedly. A queue warning or failure is recorded for coordinator inspection.

Native hook trust remains an operator-controlled runtime boundary. A file on disk or a unit test cannot prove a trusted hook executed. The coordinator prepares the exact hook sources and records the one-time trust step if the runtime requires it; no trust bypass is added. Installation and session execution are reported separately. The heartbeat never impersonates a Claude cron ID or acquires its campaign guard.

Rollback: pause registered owners, disable the project user timer, remove only the project timer units, then remove the repository hook definitions. Existing training, render processes, other hooks and other projects are untouched.
