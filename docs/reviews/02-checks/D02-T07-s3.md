Part 1: completeness

The section is an automatic evidence producer with `Surface: no`. It does not need its own menu, toolbar, shortcut, command palette, settings dialog or undo command. Local file locking and temp-file replacement do not apply to its R2 storage.

1. **present: Automatic entry from the case investigation.** The checks step follows extracted links, settles screenshots and feeds landing text into the case view before saving findings. Evidence: [analysis-workflow.ts:460](../../../src/pipeline/analysis-workflow.ts#L460).

2. **present: Bounded browser inspection and refusal paths.** Inspection inherits the follower’s URL policy, download refusal and time limits; screenshots, forms, text and frames have explicit bounds. Missing browser access returns unavailable coverage. Evidence: [expand.ts:28](../../../src/checks/expand.ts#L28), [expand.ts:615](../../../src/checks/expand.ts#L615). 3. **present: Basic password, card, hidden-text and frame detection.** Fixtures exercise login, payment, contact, article, hidden text, comments and embedded forms. Evidence: [landing-browser.test.ts:114](../../../test/node/landing-browser.test.ts#L114).

4. **missing-in-scope: All effective declared submission destinations.** The scanner chooses the **first** submit control with a nonempty `formaction`, then replaces the form’s action with it. A form with a harmless first override and a malicious second override loses the malicious destination; an ordinary submit button using the form’s original action is also omitted. An empty `formaction` is ignored despite having browser-defined behaviour. Preserve the applicable destinations and submit controls, with explicit bounded coverage. Evidence: [expand.ts:48](../../../src/checks/expand.ts#L48). The existing test covers only one override.

5. **missing-in-scope: Frame-contained lure triggers.** Frames are scanned for lure candidates, but `linkLureButtonEvidence` reads only `scans[0]`. Part 2: excellence

**Primary comparator: urlscan.io**, the closest alternative for inspecting a suspicious landing page. Its documented output includes a screenshot, retained DOM, requests/responses, links and timing information. That gives an investigator inspectable capture context beyond a derived finding. [urlscan overview](https://docs.urlscan.io/about), [Result API reference](https://docs.urlscan.io/pages/result-api-reference).

Microsoft Safe Links is the stronger comparator for automatic click-time protection, while Cloudflare Browser Isolation provides contained browsing. Neither is interchangeable with this section’s evidence producer. [Safe Links overview](https://learn.microsoft.com/en-us/defender-office-365/safe-links-about), [Browser Isolation](https://developers.cloudflare.com/cloudflare-one/remote-browser-isolation/).

1. **in-scope: Findings overstate what was established.** Field counts and destinations are collected separately at document level. A same-site login form plus an unrelated off-domain newsletter form becomes “asks for a password and sends what is typed to [newsletter host].” Moreover, an off-domain contact form with no password receives the title “A page that asks for a password.” Declared actions are described as actual transfers, although no submission occurred. Evidence: [links.ts:953](../../../src/checks/links.ts#L953), [cards.tsx:876](../../../src/web/components/evidence/cards.tsx#L876). **Target:** retain field-to-form association; distinguish declared from observed destinations; zero false password/transfer claims across contact-only, mixed-form and JavaScript-submit fixtures.

2. **in-scope: Partial instruction-scan wording corrupts the location.** The not-checked summary blindly applies `location.slice(11)`. A `landing:https://...` location loses part of its scheme; `landing-hidden:` leaves part of its prefix. This undermines the promised plain explanation precisely when the user needs recovery information. Evidence: [ai-instructions.ts:218](../../../src/checks/ai-instructions.ts#L218). **Target:** readable page/frame identification in every partial message, with golden assertions for visible and hidden landing text.

3. **out-of-scope: Viewing the visual evidence requires downloading it.** This interim card offers a file download rather than the screenshot alongside the finding. That adds a download activation and opening the downloaded file to inspect the capture. **Target:** zero additional actions for a readable preview; one keyboard-accessible activation for full resolution, returning focus to the same card. Owner: **D07 T03 §13**, already assigned the landing screenshot surface in [TODO-03-report.md:519](../../../todo/07-app/TODO-03-report.md#L519). Preserve its approved accessibility and visual requirements.

4. **out-of-scope: No measured speed advantage is demonstrated.** The follower processes up to five links sequentially within 45 seconds; each landing adds screenshot work followed by sequential frame scans. Those are bounds, not measured user latency or a comparison with urlscan. Evidence: [expand.ts:203](../../../src/checks/expand.ts#L203), [expand.ts:597](../../../src/checks/expand.ts#L597). **Target:** benchmark identical synthetic single-link, five-link, slow and damaged-page cases; report capture availability and forward-to-report p50/p95 against the comparator while meeting the project’s under-60-second median and under-three-minute p95. Owner: **D08 eval**, proposed benchmark coverage; not filed because this review is read-only. No claim that the candidate is slower is justified yet.
