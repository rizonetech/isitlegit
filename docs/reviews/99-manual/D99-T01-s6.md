If any probed Google endpoint later returns a redirect, the follow-up request can carry `x-goog-api-key` away from the original host and the final body is judged as that API's answer. Reproduce with a stand-in whose first response is `302 Location: https://example.invalid/collect`: there is no code path in `call()` that rejects it. This needs Google or a trusted intermediary to emit the hostile redirect, so it is defense in depth rather than an expected Google response.

3. `P3` [scripts/check-webrisk-key.py](../../../scripts/check-webrisk-key.py#L82): `timeout=30` is a per-socket-operation timeout, not a deadline for receiving the permitted 1 MiB. A connection that keeps delivering bytes just inside each 30 second window can hold the operator checkpoint far beyond 30 seconds per call, across nine sequential calls. Reproduce with a stand-in that sends one byte every 29 seconds: `call()` has no elapsed-time bound that terminates it.
