The strongest directly applicable alternative is Cloudflare’s dashboard plus its documented API verification and endpoint probes. Its documentation distinguishes token activity, permission groups and authentication syntax, and specifies the gateway authentication header. This comparison uses documented behaviour, not measured dashboard timings. [Cloudflare troubleshooting](https://developers.cloudflare.com/fundamentals/api/troubleshooting/), [gateway authentication](https://developers.cloudflare.com/ai-gateway/configuration/authentication/).

1. **in-scope:** Failure recovery is less actionable. Vault-read failures escape the command’s reporting path; network exceptions say only “the checks ran”; HTTP failures omit the permission or corrective action needed. Cloudflare’s guidance identifies those categories separately. **Target:** every failed stage names the affected vault item or endpoint, the required capability and one safe next action, without raw exceptions or credentials; cover missing vault access, timeout and permission denial. Evidence: [check-gateway-tokens.ts:113](../../../scripts/check-gateway-tokens.ts#L113).
2. **in-scope:** Time to useful feedback is worse than running individual endpoint probes. Evidence: [check-gateway-tokens.ts:51](../../../scripts/check-gateway-tokens.ts#L51), [check-gateway-tokens.ts:137](../../../scripts/check-gateway-tokens.ts#L137).
