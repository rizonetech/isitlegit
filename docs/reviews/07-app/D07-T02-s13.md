With a prefilled invite, the code route requires email, organisation name, consent, Create account, a mailbox switch, code entry and Sign in. No evidence compares that complete journey with Slack’s complete journey. **Target:** measure form-ready → organisation-created against the contract’s 60-second goal, separately measure first-mail → authenticated Cases, and record total inputs/submissions on the same phone/network conditions for both products.
