## Part 2: excellence

Comparator: **Microsoft 365 Admin Center (`Settings -> Domains`) and Exchange Online accepted-sender administration**, the incumbent domain and sender management workflow for Rizonetech's target SMB audience ([docs/specs/2026-10-26-phishing-invoice-analyser-design.md](file://docs/specs/2026-10-26-phishing-invoice-analyser-design.md#L9), [todo/07-app/TODO-04-member-console.md](file://todo/07-app/TODO-04-member-console.md#L418)). Microsoft 365 supports one-click Domain Connect registrar verification and provider-specific DNS guidance, while requiring a multi-step modal wizard for domain addition and removal; IsItLegit's inline disclosure and explicit consequence confirmation page are simpler on step count for adding and removing, but fall short in the areas below:

1. **in-scope: Eliminate N+1 D1 case-count queries and discarded pending-address challenge lookups on `GET /settings/domains` (Speed).** [`readClaims`](file://src/web/pages/domains-list.tsx#L132-L196) runs a separate `SELECT COUNT(*) FROM cases` query per verified domain (`forDomain`) and per single address (`forAddress`, which also uses case-sensitive `=` while `forDomain` uses ASCII `LIKE`), and when any domain is pending it calls `GET /api/org/domains` ([src/auth/domains.ts](file://src/auth/domains.ts#L524-L553)), which re-queries both tables and runs `challengeOf` (5 D1 statements each) for every pending single address even though `readClaims` discards `read.addresses`. At the 10-pending-domain and 20-pending-address limits, one page load executes over 120 D1 queries. **Target:** read the month's forwarded case counts in a single grouped query (case-insensitively on `lower(forwarded_by)`), compute challenges only for pending domains, and prove `readClaims` / `GET /settings/domains` with 10,000 cases, 10 domains and 20 addresses in under 50 ms p95 in `test/web/domains-list.test.ts`.
2. **in-scope: Give both desktop data tables explicit accessible names for screen-reader table navigation (Accessibility).** In [`DomainsTable`](file://src/web/pages/domains-list-view.tsx#L137-L141) and [`AddressesTable`](file://src/web/pages/domains-list-view.tsx#L233-L240), the outer `<section>` landmarks carry `aria-labelledby="domains-heading"` and `aria-labelledby="addresses-heading"`, but the `<table>` elements themselves have neither `aria-labelledby` nor `<caption class="sr-only">` (unlike [`TeamPage`](file://src/web/pages/team-view.tsx#L247)). 3. **out-of-scope: Manual DNS record copying instead of registrar-assisted verification (Steps).** Adding a domain still requires copying and pasting the TXT record name and value at the registrar (7+ manual actions), whereas Microsoft 365 verifies supported registrars via Domain Connect in 3 actions with zero DNS values typed. **Target:** verify a domain at a Domain Connect registrar in at most 3 actions with 0 manually typed DNS values, already owned by **D07 T04 §5** ([todo/07-app/TODO-04-member-console.md](file://todo/07-app/TODO-04-member-console.md#L244-L269)).
