Postal-mime returns the actual suspicious attachment. A crafted submitted forward can therefore redirect the investigation and suppress the excluded-message warning.

2. **P1: Quoted-printable decoding can exhaust memory below the admission limit.** [src/intake/forward.ts:169](../../../src/intake/forward.ts#L169) accumulates every decoded byte in a JavaScript number array before allocating the output. Reproduce with an `application/octet-stream; name="original.eml"` attachment, `Content-Transfer-Encoding: quoted-printable`, and an original containing `('a'.repeat(74)+'\r\n').repeat(300000)`. **Measured:** the 22,800,142-byte input terminated Node under `--max-old-space-size=128` with fatal heap exhaustion, bypassing exception handling. It fits the repository’s 25 MiB admission limit and exposes the intended extraction path to the [Worker’s 128 MB memory limit](https://developers.cloudflare.com/workers/platform/limits/#memory).

3. **P1: Boundary searching permits CPU exhaustion.** [src/intake/forward.ts:140](../../../src/intake/forward.ts#L140) compares the entire boundary at every matching byte, before checking whether the occurrence starts a line. Reproduce by passing a crafted `.eml` declaring boundary `'-'.repeat(60000)+'X'`, followed by five million hyphens. Its header fits the helper’s 64 KiB bound. **Measured:** extraction of this 5,060,047-byte input remained blocked until the probe killed it after 35 seconds. Part and nesting limits never intervene. Validate boundary length before searching and avoid rescanning long matching prefixes at arbitrary body offsets.

4. **P2: Digest originals disappear from selection and counting.** [src/intake/forward.ts:77](../../../src/intake/forward.ts#L77) discards the parent MIME type when walking children. A child without `Content-Type` inside `multipart/digest` defaults to `message/rfc822`, as specified by [RFC 2046 §5.1.5](https://www.rfc-editor.org/rfc/rfc2046.html#section-5.1.5). Reproduce with a digest containing a suspicious message, followed by an explicit benign `message/rfc822` sibling. **Measured:** extraction selects the later benign message and reports `otherOriginals: 0`; postal-mime identifies both messages in order. The suspicious original is neither selected nor counted.

5. **P2: Malformed base64 escapes the promised error type.** [src/intake/forward.ts:165](../../../src/intake/forward.ts#L165) calls `atob` outside the `ParseError` wrapper.
