3. **P2, [src/intake/mime.ts:72](../../../src/intake/mime.ts#L72): Binary attachments acquire an extra byte at EOF.** postal-mime’s line reader synthesizes LF when the final line has no terminator; this driver passes it into the attachment decoder. Binary transfer encoding requires an identity transformation, so storing those bytes violates the preservation contract. [RFC 2045 §6.2](https://www.rfc-editor.org/rfc/rfc2045.html#section-6.2)
