3. **present: Durable publication, checksum verification and read-back.** R2 receives a conditional create with SHA-256 verification before D1 records metadata. Reads retrieve persisted rows and bytes without relying on process-local state. Object-store conditional publication is appropriate here; filesystem temp-file replacement is not applicable. Evidence: [store.ts:92](../../../src/intake/store.ts#L92), round-trip and checksum tests in [store.test.ts:123](../../../test/intake/store.test.ts#L123) and [store.test.ts:210](../../../test/intake/store.test.ts#L210).

Evidence: [store.test.ts:158](../../../test/intake/store.test.ts#L158). These address interruption between writes without destructive rollback.

5. **missing-in-scope: Metadata must converge with the winning object.** Two MIME parts can have identical filenames and bytes but different declared media types. If writer A creates R2 and its D1 insert fails, writer B accepts A’s checksum but records B’s media type. The probe returned `text/html` from D1 while R2 retained `text/plain`. [store.ts:102](../../../src/intake/store.ts#L102) checks only the existing checksum, then [store.ts:120](../../../src/intake/store.ts#L120) inserts the incoming metadata. Preserve the winning object’s metadata or explicitly refuse incompatible metadata. Add failed-insert and interleaved-writer regressions asserting agreement between R2, D1 and returned metadata.

6. **missing-in-scope: Typed failures must include consuming the object body.** `get()` is caught, but `await object.arrayBuffer()` is outside that boundary at [store.ts:207](../../../src/intake/store.ts#L207). A transfer interrupted after headers arrive escapes as plain `Error`, confirmed by the probe. Include body consumption in the storage-error boundary. Add a test where `get()` succeeds but its body rejects, followed by a successful retry.

7. **present: Missing-object and cross-case read outcomes.** An expired/deleted object returns its metadata plus `missing: true`; a key belonging to another case returns `null`. Evidence: [store.test.ts:219](../../../test/intake/store.test.ts#L219). This is case scoping, not member authorization.
