Capturing reputation evidence and walkthrough use supplies none of those measurements. Add collection at the cache owner for the complete timing interval and a justified avoided-cost baseline, with comparable hit/miss populations. Test that zero-cost hit records are not interpreted as zero avoided spend.

4. **P1, line 282: floor attribution lacks its required persisted inputs.** `floorApplied` exists in the standalone floor helper, but the production agent loop computes the raised verdict directly without preserving that record. Test added detections and added false positives separately from severity increases that do not change detection.

Tests must prove that these conditions cannot become zero false positives, zero latency or a successful measurement merely because a results row exists.
