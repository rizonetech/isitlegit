**Part 2: excellence**

My strongest comparable alternative is **HashiCorp Vault Transit**, specifically its versioned keys and rewrap workflow. This is a key-management benchmark, not a replacement for IsItLegit’s bank-matching product.

- **In-scope: trustworthy replacement and completion.** Vault rotation creates a new key version. This action accepts an unchanged pair and can announce completion without checking all remaining rows. Those are substantive incident-response weaknesses, not missing polish. [Vault Transit](https://developer.hashicorp.com/vault/docs/secrets/transit).
- **In-scope: interruption handling and audit accountability.** The missing durable accounting, operation-specific failure guidance and promised regression tests prevent an operator from confidently establishing what happened after a failure. These need fixing within this section, regardless of infrastructure choice.
- **In-scope: executable operational procedure.** Vault documents concrete rotation and rewrap commands. This candidate leaves contradictory ordering and requires the operator to invent a working authenticated POST during an incident. [Vault rewrap procedure](https://developer.hashicorp.com/vault/tutorials/encryption-as-a-service/eaas-transit-rewrap).
- **Out-of-scope: continuity through versioned keys.** Vault retains older versions for decryption while new encryption uses the latest version. IsItLegit temporarily refuses matching and adding during migration. Equivalent continuity would require a broader design for both encryption and HMAC matching, beyond this endpoint. [Vault Transit](https://developer.hashicorp.com/vault/docs/secrets/transit).
- **Out-of-scope: cryptographic isolation.** Vault can grant rewrap permission without revealing plaintext to the rewrap caller. Here the Worker holds both key pairs and decrypts each account during migration. Moving that boundary to a dedicated cryptographic service is architectural work. [Vault Transit](https://developer.hashicorp.com/vault/docs/secrets/transit).

There is no evidence that this candidate performs key replacement better than that benchmark.
