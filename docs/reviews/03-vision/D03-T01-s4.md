1. `P2` [src/meta/cache.ts:32](../../../src/meta/cache.ts#L32) `canonical()` silently collides distinct non-JSON `params`. `Date`, `Map` and `Set` values all encode as `{}`, while `undefined`, `NaN` and infinities encode as `null`. Reproduce with two `cacheKey` calls differing only in `params: { when: new Date("2026-01-01") }` versus `params: { when: new Date("2027-01-01") }`, or a `Map` with different entries: they produce one key, so [src/meta/cache.ts:108](../../../src/meta/cache.ts#L108) can serve the first artefact's verdict for the second. `params` is typed `unknown` at [src/meta/cache.ts:26](../../../src/meta/cache.ts#L26), so these values are accepted rather than refused.
