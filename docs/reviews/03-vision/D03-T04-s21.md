4. **P2, [§21:674](../../../todo/03-vision/TODO-04-glimmer.md#L674): Range allocation and redistribution are unspecified.** Two healthy hosts serving concurrently proves neither useful balancing nor recovery when one becomes slow. Add unequal-speed, mid-transfer stall and disconnect tests proving faster mirrors take remaining work without overlapping writes, exceeding four total connections or unnecessarily refetching completed ranges.

5. **P2, [§21:674](../../../todo/03-vision/TODO-04-glimmer.md#L674): The inherited safety rules are not tested under simultaneous sources.** Existing failover tests exercise a current URL; notably, `charge()` ignores failures from URLs already left. Require concurrent tests for source-specific blame, the single failure budget, `Retry-After`, rate floors, source locking and aggregate limits. Also define and test incompatible validators, changed lengths, ignored ranges and refused redirects while another mirror is writing, including cancellation before restart and atomic, fully SHA-256-verified publication.

6. **P2, [§21:674](../../../todo/03-vision/TODO-04-glimmer.md#L674): Mixed-source digest failure needs an explicit recovery mode.** Current recovery discards the mixed partial and retries from the current URL so a subsequent mismatch can identify the bad source. Add a bounded isolated-source retry policy, retain contributor provenance across resume, and test one corrupt mirror alongside one healthy mirror without blaming the healthy contributor or publishing the mixture.

Interleave matched runs and retain raw timings and host-load conditions: the current harness runs each tool’s repetitions together, allowing changing host load to decide a margin below 1.00.
