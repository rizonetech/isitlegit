1. **P1, [lines 66, 74 and 81](../../../todo/03-vision/TODO-03-sam-logos.md#L66): Asset-use permission is unproven.** An official source URL and private storage do not satisfy spec 4.4’s “licence-safe sources” or the hackathon requirement to record permitted use in `NOTICE.md` or `eval/DATASETS.md`. Add a recorded licence or permission basis for each reference, with unsupported assets refused and listed as missing. This is a missing project gate, not a conclusion that these uses are unlawful.

2. **P2, [lines 81, 85 and 91](../../../todo/03-vision/TODO-03-sam-logos.md#L85): The checkpoint can certify fewer than 20 real brands.** Eighteen real references plus the two fictional references satisfy the specified count. The selector-table test also checks that entries belong to the brand table without proving every brand is represented. Require at least 20 distinct real brands, both fictional references separately, and exactly one disposition per real brand across `logos` and `missing`. Test omitted brands, duplicates and 18 real plus two fictional references.

3. **P2, [lines 82, 84 and 85](../../../todo/03-vision/TODO-03-sam-logos.md#L84): Stored bytes are not verified against their provenance.** The plan records SHA-256 and dimensions but only requires object existence afterward. A changed local file can therefore be uploaded under an old manifest, pass `--check`, and reach §3 with the wrong hash or image. Require complete manifest/file validation before any put, equality with the intended index on read-back, and verification of stored image hashes, types and dimensions. Test an altered image and a successful read returning the wrong index.

4. **P2, [lines 83 and 84](../../../todo/03-vision/TODO-03-sam-logos.md#L83): Reloads have no consistent recovery or reverse path.** Replacing fixed logo keys before publishing the index leaves the previous index pointing at changed bytes if a later upload fails. Per-file temporary renames have the same limitation during local recapture. Add generation-based publication or an equivalent recoverable replacement protocol, retain the previous complete generation, and test interrupted replacement, retry and restoration. The repository’s existing `scripts/load-brands.ts` is the stronger operational alternative here: it preserves the previous value and implements verified restoration.

5. **P2, [line 83](../../../todo/03-vision/TODO-03-sam-logos.md#L83): Capture failure recovery has no bounded, executable proof.** Live sites can stall, selectors can disappear, and fallback image downloads can fail. The section promises to record a missing brand and continue, but defines neither an overall per-brand deadline nor tests exercising that path. Add bounded capture/fetch operations, browser cleanup on failure, and deterministic tests proving a failed brand is recorded while the following brand still captures successfully.

6. **P3, [lines 78 and 79](../../../todo/03-vision/TODO-03-sam-logos.md#L78): The completion conditions contradict the permitted formats.** They require `<slug>.png`, although line 72 explicitly allows JPEG and WebP references. Make both conditions check the validated extension and indexed key so an allowed fallback can satisfy them.
