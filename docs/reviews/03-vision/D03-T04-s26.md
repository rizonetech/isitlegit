1. **P2, [§26:831](../../../todo/03-vision/TODO-04-glimmer.md#L831): Prototype calls are not trusted browser calls.** Page scripts can replace the prototypes too. 2. **P2, §26:831: Reader failures can become false labels.** `readFrame` catches every evaluation failure and returns empty text or false form flags; `frameShown` similarly turns failures into “hidden.” A visible sign-in frame can therefore be stored with `has_login_form: false`. Require an explicit unreadable state that retries or refuses the capture, with tests distinguishing unreadable frames from genuinely hidden or detached frames.

3. **P2, [§26:834](../../../todo/03-vision/TODO-04-glimmer.md#L834): The wording tests miss ordinary rendered variations.** Direct probes confirmed that `unusable()` accepts both `Press\n&\nHold` and a recognised wall following 2,000 characters of navigation. Require whitespace-normalised detection across the relevant visible content, including overlays appended after long navigation, and rendered regression fixtures for both cases.

4. **P2, §26:831 and §26:834: Wall detection does not cover the render’s full frame and shadow tree.** `readWalls` runs only in the main frame; challenge wording relies on text extraction that does not explicitly traverse shadow roots. A nested CAPTCHA, a shadow-root challenge, or instructions drawn in an image or canvas can cover otherwise acceptable page text without triggering refusal. Require detection or explicit refusal of these challenge presentations, with fixtures that reach the batch and prove nothing is stored.

5. **P2, §26:831: Capture consistency is unspecified.** Text, form flags, title, walls, screenshot and final URL are read separately while scripts continue running. A delayed navigation or challenge appearing between those reads can pair earlier benign text and labels with a later wall screenshot. Require a consistent capture or a bounded retry when the relevant document or content changes, tested with a transition during extraction.

6. **P2, [§26:835](../../../todo/03-vision/TODO-04-glimmer.md#L835): Recheck cannot establish the promised clean store.** It checks only the first 2,000 characters of stored text. Require the same refusal fixtures to fail both fresh admission and stored-page auditing.

7. **P2, §26:835 and [§26:838](../../../todo/03-vision/TODO-04-glimmer.md#L838): Recheck accepts unverified files and silently skips malformed metadata.** It uses `manifest({ tolerant: true })` and `readPage()` without checking either file’s full SHA-256. Require complete integrity checking before accepting a page as clean, explicit accounting for damaged records, and a failing audit status for unresolved damage. Zero removals alone is insufficient.

8. **P2, §26:835: Removal and its exclusion record are not recoverable together.** `recheckStored` deletes first and appends the journal event afterward.
