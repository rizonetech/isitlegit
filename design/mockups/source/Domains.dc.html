How to forward an email for checking

Forward it as an attachment, so the original sender details come with it. A normal forward loses them.

Outlook desktop

Select the email, then Home, More, Forward as attachment. Send it to check@isitlegit.co.za.

Outlook on the web

Open the email, choose More actions, Forward as attachment.

Gmail

Open the email, choose More, Forward as attachment.
